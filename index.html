Instrucciones

  1. Elige el tipo de documento y escribe tu nombre como responsable.
  2. Escribe el nombre del documento y adjunta su archivo o archivos.
  3. Si tienes más documentos del mismo tipo, usa “Agregar otro documento de este tipo”: solo pide el nombre y el archivo.
  4. Para otro tipo (por ejemplo, después de las fichas técnicas, un manual), usa “Agregar otro tipo de documento”.
  5. Pulsa “Enviar documentación” y no cierres la página hasta ver tus folios.
